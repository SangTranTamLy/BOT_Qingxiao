Official project information

Simple, permission-based TikTok analytics for Discord.

Qingxiao TikTok Analytics helps users connect their own TikTok account through TikTok Login Kit and view the information they explicitly authorize. The project also includes Qingxiao EJ, a Discord bot for emoji uploads and public TikTok link analysis.

How access works

Users sign in directly on TikTok and approve the requested permissions. The project does not ask for TikTok passwords or browser cookies.

Your choices

Users may decline authorization, stop using the connection, or request that their connected data be removed through the Discord server where the bot is installed.
